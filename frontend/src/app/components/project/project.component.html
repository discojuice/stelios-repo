Full-stack deployment project

Project's logic

A full-stack web application built with Spring Boot, Angular, PostgreSQL, Docker, JaCoCo and Render deployment.

01

Repository setup

Created the project repository in GitLab and prepared the codebase for version control.

Gitlab repo
02

Full-stack architecture

Built a Spring Boot backend and Angular frontend, with controller, service, entity and repository layers.

03

PostgreSQL with Docker

Used Docker to run a PostgreSQL database locally for development and testing.

04

Local build and testing

Tested the application locally, verified the backend and frontend integration, and built the project.

05

Render deployment

Deployed the backend, frontend and database on Render to make the application available online.

Render project dashboard
06

GitHub synchronization

Created a GitHub account and synchronized it with the GitLab project repository.

07

Code coverage

Configured JaCoCo to generate coverage reports and measure test coverage for the backend.

08

Uptime

Used UpTimeRobot with a ping to the server side just to keep the backend awake for prod environment.
